Windows 11のこのPCで、本番のAudioMonitorServiceを使い、テスト用の小音量の音を実際に出して検証した。

- アプリの0.25秒音：PID、実行ファイル名、フルパスが再生したテストプロセスと一致。

実行：`AudioCulprit.Tests.exe --integration --sources`。39チェック成功。
`--sources`はこのPCのEdgeインストール先を使う、任意の実環境テスト。通常のプロファイルは使用せず、終了時に自分で起動したブラウザプロセスツリーを終了する。
